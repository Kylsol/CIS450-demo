Response:
That usually happens when your “non-black mask” still has *some* non-black pixels touching the top/bottom (often faint noise or warped seams), so the largest contour’s bounding box spans the full height.

Use a more robust crop: **flood-fill the background from the edges**, then crop to the remaining “content” region.

## Fix: Flood-fill background, then crop to content

1. Add this import at the top (with your other imports):

```python
import numpy as np
```

2. Replace your current crop block with this one (same location: after `status == OK` and before `imwrite`):

```python
# --- Crop black borders (robust: flood-fill background) ---
gray = cv.cvtColor(pano, cv.COLOR_BGR2GRAY)

# Make a mask of "probably content"
# Increase 5 -> 10 or 15 if you still get no top/bottom crop
_, mask = cv.threshold(gray, 10, 255, cv.THRESH_BINARY)

# Clean small specks so they don't prevent cropping
kernel = cv.getStructuringElement(cv.MORPH_RECT, (9, 9))
mask = cv.morphologyEx(mask, cv.MORPH_OPEN, kernel)
mask = cv.morphologyEx(mask, cv.MORPH_CLOSE, kernel)

# Flood-fill from corners to mark background
h, w = mask.shape[:2]
ff = mask.copy()
ff = cv.copyMakeBorder(ff, 1, 1, 1, 1, cv.BORDER_CONSTANT, value=0)  # avoid edge issues
flood_mask = np.zeros((h + 2 + 2, w + 2 + 2), np.uint8)  # needs to be (H+2, W+2) for floodFill on bordered img

# Flood fill background starting from the four corners
cv.floodFill(ff, flood_mask, (0, 0), 255)
cv.floodFill(ff, flood_mask, (w + 1, 0), 255)
cv.floodFill(ff, flood_mask, (0, h + 1), 255)
cv.floodFill(ff, flood_mask, (w + 1, h + 1), 255)

# Background is now 255 in ff; content holes are 0. Invert to get content area.
ff = ff[1:-1, 1:-1]  # remove border
content = cv.bitwise_not(ff)

# Find bounding rect of content pixels
ys, xs = np.where(content > 0)
if len(xs) and len(ys):
    x0, x1 = xs.min(), xs.max()
    y0, y1 = ys.min(), ys.max()
    pano = pano[y0:y1+1, x0:x1+1]
```

3. Keep your save lines the same:

```python
out_file = "result.jpg"
cv.imwrite(out_file, pano)
print("✅ Panorama saved as:", out_file)
```

### If it still won’t crop top/bottom

Bump the threshold line:

```python
_, mask = cv.threshold(gray, 20, 255, cv.THRESH_BINARY)
```

That forces faint dark pixels (near-black) to be treated as background, which usually unlocks top/bottom cropping.
